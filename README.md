# 📈 日本株価分析・予測アプリ

Yahoo! Finance APIを活用した日本株式のリアルタイム情報取得・分析・予測アプリケーションです。

## 🌟 主な機能

### 1. リアルタイム株価情報取得
- 日本の上場企業の最新株価を表示
- 銘柄コード入力で簡単検索
- 詳細な株価情報（始値、高値、安値、出来高、時価総額など）
- 52週高値・安値、PER、配当利回りなどの指標

### 2. 関連ニュース取得
- 銘柄に関する最新ニュース5件を自動取得
- Yahoo! Financeからのリアルタイムフィード
- ニュースソース、公開日時の表示
- 外部リンクで詳細記事へアクセス可能

### 3. 株価予測（3ヶ月先）
- 過去のデータに基づく統計的予測
- 線形回帰モデルによる価格予測
- 95%信頼区間の表示
- テクニカル指標（移動平均、ボラティリティ、トレンド）
- AI分析による詳細な解説

### 4. ユーザーフレンドリーなUI
- モダンで直感的なデザイン
- レスポンシブ対応（PC・タブレット・スマホ）
- 人気銘柄のワンクリック検索
- リアルタイムローディング表示

## 📋 必要な環境

- Python 3.8以上
- pip（Pythonパッケージマネージャー）
- インターネット接続（Yahoo! Finance APIにアクセスするため）

## 🚀 インストール方法

### 1. リポジトリをクローン

```bash
git clone <repository-url>
cd app-07-3
```

### 2. 依存パッケージをインストール

```bash
pip install -r requirements.txt
```

または、個別にインストール：

```bash
pip install Flask Flask-CORS yfinance pandas numpy requests beautifulsoup4 scikit-learn
```

## 💻 使い方

### 1. アプリケーションを起動

```bash
python app.py
```

### 2. ブラウザでアクセス

起動後、以下のURLにアクセス：

```
http://localhost:5000
```

### 3. 銘柄を検索

- 入力欄に銘柄コードを入力（例：7203）
- 「検索」ボタンをクリック、またはEnterキーを押す
- または、人気銘柄タグをクリック

### 4. 情報を確認

- **株価情報**: 現在価格、変動率、詳細情報を確認
- **ニュース**: 最新の関連ニュース5件を閲覧
- **予測**: 3ヶ月先の株価予測と分析結果を確認

## ⚠️ 注意事項

1. **投資助言ではありません**
   - このアプリの予測は統計的な推定であり、投資の助言や推奨ではありません
   - 実際の投資判断は自己責任で行ってください

2. **データの遅延**
   - Yahoo! Finance APIからのデータには若干の遅延がある場合があります
   - リアルタイム取引には適していません

3. **予測の精度**
   - 株価予測は過去のデータに基づいており、将来を保証するものではありません
   - 市場の急激な変動や予期せぬイベントには対応できません

4. **利用制限**
   - Yahoo! Finance APIには利用制限があります
   - 頻繁なアクセスは控えてください

## 🔐 セキュリティ

- APIキー不要（yfinanceはパブリックAPIを使用）
- CORS設定により安全なクロスオリジン通信
- ユーザーデータの保存なし（プライバシー保護）

## 🐛 トラブルシューティング

### エラー: "株価データが見つかりません"
- 銘柄コードが正しいか確認してください
- 東京証券取引所に上場している銘柄か確認してください

### エラー: "モジュールが見つかりません"
```bash
pip install -r requirements.txt
```
を実行して、すべての依存パッケージをインストールしてください。

### ポート5000が使用中
app.pyの最後の行を編集してポートを変更：
```python
app.run(debug=True, host='0.0.0.0', port=8000)  # 5000 -> 8000
```
